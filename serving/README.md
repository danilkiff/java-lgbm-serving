# Инференс RBA модели на JVM

Что обеспечивает:

- инференс обученной в Python модели LightGBM через Panama FFM;
- конвейер decline-explain и нативные SHAP-коды причин.

FFM грузит `lib_lightgbm` из `native/.venv` - ту же, что исполняет Python,
отсюда битово точный паритет. Тесты паритета читают эталоны из `refs/`: сперва
`make refs` в корне репозитория. Тесты конвейера обходятся закоммиченной
фикстурой и эталонов не требуют.

Путь к библиотеке переопределяется свойством `lgbm.library.path` или переменной
`LGBM_LIBRARY_PATH`.

## Команды

`make help` печатает список целей.

## REST API

Примеры запросов в `clients/http/scorer.http`.
